# Mixed SDK Samples

This directory contains samples demonstrating the usage of multiple SDKs from the Meta VR OS SDK within a single application.

## Samples

| Name | SDKs | Description |
| ---- | ---- | ----------- |
| [Meta VR OS SDK Versioning](./VersioningSample/) | JSDK<sup>1</sup>, Utility Library<sup>2</sup> | Demonstrates querying the version of Meta VR OS SDK on the device with JSDK, and comparing it to a constant value with Utility Library |

1. **JSDK:** Meta VR OS Java Software Development Kit
2. **Utility Library:** Meta VR OS Utility Library
